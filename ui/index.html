oner settings

One setup for every coding agent you use

oner keeps the rules and skills your coding agents work by in one place and installs them into each agent you use: Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot CLI, OpenCode, and Grok Build. You choose here. The shared files never change, so an update never collides with your choices.

  • The same agent everywhereOne set of rules for how an agent talks, decides, edits, and checks its work, in every tool.
  • From task to pull request/oneshot takes a feature or a bug through spec, build, checks, and review, and stops once for your decisions.
  • Review by other modelsA change is read by models other than the one that wrote it, before you see it.
  • Nothing to maintain by handA change here reaches every agent on its own. Updates arrive when you ask your agent for them.
