# T3 Code

Read the installed version, native storageCleanup settings and project overrides before
interpreting retained worktrees. Settled retention and automatic settlement on merge are
separate. Preserve the user's automatic settlement settings because a thread can carry many PRs.
Prefer native retention and supported APFS checkout caching. That cache covers tracked Git
files. pnpm can share package contents without a mutable node_modules symlink across branches.

T3 is optional. Missing or unreadable records preserve potentially managed work. Only settled,
archived or deleted tasks without active work qualify for normal Git deletion proofs. T3's
branch references remain even after a checkout is removed. Do not bypass unknown state with --drop.

For excess dependency and build output in retained worktrees, preview
`dev-tidy --reclaim-caches --skip-git --skip-turbo --skip-wp-env --skip-docker --kept`, then repeat the same scope
with --yes after authorization. It removes ignored, untracked node_modules and .next directories
in known idle T3 worktrees. Resuming requires installing dependencies and rebuilding. Active
host processes, pending tasks, open oneshot runs, nested Git ownership and --keep preserve caches.
A stored ready provider session alone blocks whole-worktree deletion but not cache reclamation.

Read [the command reference](../dev-tidy.md) for the installed state schema and exact guards.
