# Sources

Adapted from [Jakub Krehel's interface skills](https://github.com/jakubkrehel/skills/tree/267330e1adfc66a718fb65fa6918c1f06d0a689e)
at `267330e1adfc66a718fb65fa6918c1f06d0a689e`, and
[Vercel's Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/tree/e3d624baaf29dc1fc645aff3e38f03e564d2d6b1)
at `e3d624baaf29dc1fc645aff3e38f03e564d2d6b1`, inspected on 2026-09-30, and
[Impeccable](https://github.com/pbakaus/impeccable/tree/8a0e198da34ebc5b936a9d5975fb7a3b1cf353b7)
at `8a0e198da34ebc5b936a9d5975fb7a3b1cf353b7` (Apache 2.0), inspected on 2026-10-15, for the
typography, color, and browser-surface checks. Their license notices are included alongside
this file.

Retained interaction checks, contextual typography and layout review, accessible names,
focus, touch behavior, real content, and explicit verification limits. Replaced universal
style values and review verdicts based on taste with project authority and three distinct
finding kinds: observed failure, system conflict, and design proposal. General code review
and existing `break-ui` checks remain owned by the repository's skills.
